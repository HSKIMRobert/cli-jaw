Session Commands

会话命令用于管理当前的 CLI-JAW 对话：查看帮助、浏览命令、检查状态、清除历史记录、压缩上下文、重置状态以及在对话中途重新引导智能体。这些是你在交互使用中最常用的命令。

所有会话命令以 / 开头，可直接在聊天输入框中输入。你也可以使用自然语言触发它们 — CLI-JAW 同样理解韩语和英语。请参阅下方每个命令的"~해줘"提示。

Quick Reference

CommandDescription
/help [command]显示所有命令或特定命令的帮助信息
/commands打开支持模糊搜索的命令面板
/status显示当前会话状态和诊断信息
/clear清除对话历史记录
/compact [instructions]压缩上下文并保留关键信息
/reset [confirm]完全重置会话 — 清除历史记录、状态和已加载的技能
/steer <prompt>在对话中途将智能体重定向到新方向

Commands in Detail

/help

/help [command]

显示 CLI-JAW 命令的文档。不带参数调用时，会按类别分组列出所有可用命令。提供命令名称时，会显示该特定命令的详细用法、参数和示例。

参数：

参数必填描述
command否要获取详细帮助的特定命令名称（不含 / 前缀）
# List all commands
/help

# Get detailed help for a specific command
/help compact

# Help for the steer command
/help steer
"~해줘" 提示： "도움말 보여줘"、"명령어 뭐 있어?"、"compact 사용법 알려줘" 都会映射到 /help。CLI-JAW 会检测你的意图并显示相关文档。

/commands

/commands

打开命令面板 — 一个交互式、可搜索的所有斜杠命令列表。面板支持模糊匹配，你可以输入部分名称来快速找到所需内容。这是发现你从未使用过的命令的最快方式。

面板会显示每个命令的类别、简要描述和键盘快捷键（如果有的话）。选择一个命令可以立即执行，或将其插入输入框以便进一步编辑。

# Open the command palette
/commands

# In the palette, type to filter:
# "mod" → shows /model, /model-list
# "sk" → shows /skill, /skill load, /skill list
"~해줘" 提示： "명령어 팔레트 열어줘"、"커맨드 목록 보여줘" 会触发命令面板。你也可以说 "뭐 할 수 있어?" 来获取功能的对话式概览。

/status

/status

显示当前会话的综合快照。包括活动模型和 CLI 后端、已加载的技能、对话 token 数量、内存使用情况、活动目标、已连接的集成（Telegram、Discord 等）以及服务器健康状态。对于调试或理解智能体为何有某种行为非常有用。

状态字段包括：

字段描述
Model当前活动的 LLM（例如 claude-opus-4-6、gpt-4.1）
CLI活动的 CLI 后端（Claude Code、Codex 等）
Skills当前已加载的技能列表及其活动/非活动状态
Tokens当前上下文窗口使用量（已使用 / 最大值）
Goals活动目标及其完成状态
Integrations已连接的服务（Telegram、Discord、Electron）
Memory内存索引大小和上次同步时间戳
Uptime当前会话已运行的时长
# Check current session state
/status

# Example output:
# Model: claude-opus-4-6 via Claude Code
# Skills: dev (active), github (active), memory (active) + 7 more
# Tokens: 42,318 / 200,000 (21%)
# Goals: 2 active, 1 completed
# Uptime: 1h 23m
"~해줘" 提示： "지금 상태 보여줘"、"현재 세션 정보"、"토큰 얼마나 썼어?" 都会解析为 /status。智能体会以可读格式呈现状态信息。

/clear

/clear

清除当前会话的对话历史记录。这会从上下文窗口中移除所有先前的消息，让你可以重新开始，同时保留已加载的技能、活动目标和会话配置。智能体会保留其记忆（持久化知识），但会丢失当前对话的线索。

这比 /reset 更轻量 — 可以理解为在同一工作空间中关闭一个聊天标签页并打开一个新的。技能保持加载状态，目标保持活动状态，配置也会保留。

保留与清除的内容：

保留清除
已加载的技能对话消息
活动目标上下文中的工具结果
记忆（MEMORY.md、SQLite 索引）临时推理状态
会话配置对话范围内的变量
# Clear conversation history
/clear

# Typical flow: long conversation gets noisy, clear and continue
/clear
"이전 맥락 필요없어, 새로운 작업 시작하자"
"~해줘" 提示： "대화 초기화해줘"、"히스토리 지워줘"、"대화 내역 클리어해줘" 都会触发 /clear。当对话变长时，这是你想要一个全新线程的首选命令。

/compact

/compact [instructions]

通过总结之前的交流来压缩当前对话上下文，同时保留关键决策、代码更改和重要上下文。这对于即将达到上下文窗口限制但又不想完全丢失线索的长会话至关重要。

智能体会读取完整对话，识别关键信息（已做的决策、修改的文件、遇到的错误、进行中的目标），并生成一份密集的摘要来替换完整历史记录。你可以选择性地传入指令来指导摘要应侧重的内容。

参数：

参数必填描述
instructions否自然语言指导，说明在摘要中应优先保留哪些内容（例如 "keep the API decisions"、"focus on the auth flow"）
# Basic context compression
/compact

# Compress with specific focus
/compact keep the database schema decisions and migration plan

# Compress focusing on errors and fixes
/compact focus on the bugs we found and how we fixed them

# Korean instructions work too
/compact API 설계 결정사항만 유지해줘
"~해줘" 提示： "컨텍스트 줄여줘"、"대화 요약해줘"、"컨텍스트 압축해줘"、"토큰 아껴줘" 都会映射到 /compact。当你看到 token 使用率超过 60-70% 时，这是你最好的帮手。

/reset

/reset [confirm]

执行完整的会话重置。这是终极选项 — 它会清除对话历史记录、卸载所有动态加载的技能、重置活动目标，并将会话恢复到初始启动状态。只有持久化记忆（MEMORY.md 和 SQLite 索引）能在重置后保留。

由于此操作具有破坏性，命令会在执行前要求确认。传入 confirm 可跳过确认提示并立即执行。

参数：

参数必填描述
confirm否传入字面量 confirm 以跳过确认提示

重置的内容：

重置保留
对话历史记录持久化记忆（MEMORY.md）
已加载的技能（恢复为默认值）SQLite 记忆索引
活动目标服务器配置
临时状态和变量CLI 后端选择
进行中的工具调用集成连接
# Reset with confirmation prompt
/reset
# Agent asks: "This will clear all session state. Confirm? (y/n)"

# Skip confirmation
/reset confirm

# Typical flow: session is confused, start completely fresh
/reset confirm
"처음부터 다시 시작하자. Next.js 프로젝트 만들어줘."
"~해줘" 提示： "완전히 초기화해줘"、"세션 리셋해줘"、"처음부터 다시 시작"、"전부 지우고 새로 시작" 都会触发 /reset。除非你包含 "confirm" 或表达了强烈意图，否则智能体会在执行前始终进行确认。

/steer

/steer <prompt>

在不清除历史记录的情况下重定向智能体。当智能体朝着错误的方向前进，或者你想在保留现有上下文的同时切换到不同的方法时使用。引导提示会作为高优先级系统级指令注入，覆盖智能体当前的轨迹。

这比 /clear 更精准 — 你保留完整的对话历史记录和上下文，但智能体会根据你的新方向重新评估其方法。它非常适合路线修正："停止做 X，改为做 Y。"

参数：

参数必填描述
prompt是描述新方向、方法或约束的自然语言指令
# Redirect approach
/steer stop using class components, use hooks instead

# Change language/framework
/steer switch to TypeScript for all new files

# Adjust behavior
/steer be more concise, skip explanations, just show code

# Korean works naturally
/steer 설명 생략하고 코드만 보여줘

# Pivot task direction
/steer 이 방식 말고 WebSocket으로 구현하자
"~해줘" 提示： "방향 바꿔줘"、"다른 방법으로 해줘"、"이렇게 말고 저렇게 해"、"접근 방식 바꿔" 都会触发引导行为。你也可以直接用自然语言表述新方向 — 智能体会捕捉到转向意图。/steer 使其更加明确和有力。

When to Use Which

选择合适的会话命令取决于你希望保留多少状态：

场景命令原因
对话过长，接近 token 限制/compact在释放 token 的同时保留关键决策
当前话题已结束，开始新任务/clear全新对话，工作空间状态保持不变
智能体走错了方向/steer在不丢失上下文的情况下纠正路线
会话严重混乱或损坏/reset终极选项 — 完全重启
记不住命令名称/commands可搜索的全部可用命令面板
需要检查 token 使用量或已加载的技能/status一目了然的会话诊断信息
刚接触 CLI-JAW，探索功能中/help内置于聊天中的文档

Command Lifecycle

会话命令在 CLI-JAW 技术栈的不同层级上运行：

  • /help 和 /commands 是只读的 — 它们显示信息而不修改状态。
  • /status 从多个子系统（模型、技能、记忆、目标）读取数据并汇总为快照。
  • /clear 清除消息缓冲区，但保留会话外壳（技能、配置、目标）不变。
  • /compact 重写消息缓冲区 — 它读取所有消息，生成摘要，然后用压缩版本替换完整历史记录。
  • /steer 在不触碰消息历史记录的情况下，向系统上下文注入优先级指令。
  • /reset 销毁整个会话（消息 + 技能 + 目标 + 状态），并从启动默认值重新初始化。
自然语言始终有效。你永远不必记住斜杠命令。说 "대화 지워줘" 和输入 /clear 效果相同。斜杠命令的存在是为了精确和速度，但 CLI-JAW 的意图检测会处理其余一切。
