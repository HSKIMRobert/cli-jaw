更新日志

CLI-JAW 2.0.0 正式版以来的发布历史。

v2.0.17 — 2026-05-29

新功能

  • IDE 键盘快捷键：Cmd+W 关闭标签页，Cmd+1-4 切换标签页，Cmd+Shift+[/] 标签页导航
  • 浏览器面板快捷键：Cmd+L（URL 栏），Cmd+R（刷新），Cmd+Shift+R（强制刷新），Cmd+Left/Right（前进/后退）
  • 终端快捷键：Cmd+K（清屏），Cmd+T（新建标签页）
  • Cmd+Shift+B 切换左侧边栏（实例列表）
  • 移除右侧面板宽度上限 -- 可自由扩展
  • cli-jaw goal CLI 子命令（set/status/done/cancel/update/history）
  • 目标续行功能现在在 PABCD 阶段中触发

修复

  • Electron 权限策略：默认允许，使用安全拒绝列表
  • 移除预览权限提示（不再出现 "background-sync blocked" 提示）
  • 前端 tsc 类型安全：PanelBusAction 联合类型
  • 焦点范围快捷键（浏览器/终端操作仅在获得焦点时触发）
  • PanelLayoutProvider 过期闭包修复
  • Cmd+K 冲突解决（保留 CommandPalette，移除菜单加速器）

v2.0.14 – v2.0.16 — 2026-05-27 ~ 28

新功能

  • Electron 41 桌面应用 -- macOS 通用 DMG
  • 内置终端（xterm.js + node-pty，多标签页）
  • 差异查看器、文件夹面板、浏览器面板（加固 webview）
  • 右侧边栏双分屏，支持拖拽调整大小
  • 底部面板：终端 / 浏览器 / 日志 / 活动标签页
  • 面板状态持久化
  • Claude 快速模式转发
  • claude-opus-4-8 模型 ID 预置

v2.0.5 – v2.0.13 — 2026-05-10 ~ 26

新功能

  • 访谈模式：结构化已知/未知追踪器，每轮 1-3 个问题
  • 目标系统：无长度限制，自动续行，计时器泄漏修复
  • Dashboard git diff API + 差异面板渲染
  • Jawsidian 图视图控件
  • Web AI 观察/自动化原语
  • steerPrompt 在 Web/CLI 上触发 submitMessage

修复

  • AGY/Grok 恢复加固
  • 桌面面板 web/Electron 分离
  • CI 契约恢复

v2.0.1 – v2.0.4 — 2026-05-02 ~ 09

新功能

  • 笔记图片粘贴（远程 URL、本地拖拽、剪贴板）
  • 客户端图片压缩（>5MB 自动缩放）
  • 浏览器标签页生命周期持久化
  • Web AI 会话管理 + 标签页池复用
  • 笔记内联标题布局
  • 技能安装时传播至所有实例

修复

  • Dashboard 侧边栏数据过期问题
  • Discord AllowedMentions 默认值
  • 上传内容验证加固
  • 认证路径和进程检查加固
  • launchd 状态显示实际 plist 端口
  • npm 漏洞补丁

v2.0.0 正式版 — 2026-05-02

初始正式版发布，包含多实例仪表盘、Jawsidian 笔记、看板、员工系统、PABCD 编排、195 个技能、目标系统、Telegram/Discord 集成和语音识别。
