빠른 시작

CLI-JAW를 설치하고 5분 안에 첫 AI 에이전트 세션을 시작하세요.

사전 요구사항

  • Node.js 20+ — nodejs.org
  • npm (Node.js에 포함)
  • 최소 하나의 제공자(Anthropic, OpenAI, Google)의 API 키

설치

macOS / Linux

npm install -g cli-jaw

Windows

Windows는 WSL(Windows Subsystem for Linux)이 필요합니다. 먼저 WSL을 설치한 후, 시작 메뉴에서 Ubuntu를 열고 거기서 명령어를 실행하세요.
# WSL Ubuntu 터미널에서:
npm install -g cli-jaw

Windows 상세 가이드: Windows 설정

초기 설정

jaw init

설정 마법사가 다음을 안내합니다:

  1. 기본 CLI 선택 (Claude Code, Codex, Gemini CLI 등)
  2. API 키 설정
  3. 서버 포트 설정 (기본값: 3457)

API 키 설정

API 키는 ~/.cli-jaw/settings.json에 입력합니다:

{
  "anthropic": { "apiKey": "sk-ant-..." },
  "openai": { "apiKey": "sk-..." },
  "google": { "apiKey": "AIza..." }
}

설치 확인

jaw doctor

설정을 확인하고 문제가 있으면 보고합니다.

문제 해결

에러해결 방법
command not found: jawnpm 글로벌 bin이 PATH에 있는지 확인. npm bin -g로 경로 확인.
EACCES permission deniedsudo npm install -g cli-jaw를 사용하거나 npm 권한 수정.
node: command not foundnodejs.org에서 Node.js 20+ 설치.
