변경 이력

CLI-JAW 2.0.0 GA 이후 릴리스 히스토리입니다.

v2.0.17 — 2026-05-29

기능

  • IDE 키보드 단축키: Cmd+W 탭 닫기, Cmd+1-4 탭 전환, Cmd+Shift+[/] 탭 이동
  • 브라우저 패널 단축키: Cmd+L (URL), Cmd+R (새로고침), Cmd+Shift+R (강제 새로고침), Cmd+Left/Right (뒤로/앞으로)
  • 터미널 단축키: Cmd+K (지우기), Cmd+T (새 탭)
  • Cmd+Shift+B로 왼쪽 사이드바(인스턴스) 토글
  • 오른쪽 패널 너비 제한 제거 -- 자유롭게 확장 가능
  • cli-jaw goal CLI 하위 명령어 (set/status/done/cancel/update/history)
  • Goal 연속 실행이 PABCD 단계에서도 발동

수정

  • Electron 권한 정책: 기본 허용 + 안전 차단 목록 방식으로 변경
  • 미리보기 권한 알림 제거 ("background-sync blocked" 메시지 해소)
  • 프론트엔드 tsc 타입 안전성: PanelBusAction 유니온 적용
  • 포커스 범위 단축키 (브라우저/터미널 동작은 해당 영역에 포커스될 때만 실행)
  • PanelLayoutProvider 오래된 클로저 수정
  • Cmd+K 충돌 해결 (CommandPalette 유지, 메뉴 가속키 제거)

v2.0.14 – v2.0.16 — 2026-05-27 ~ 28

기능

  • Electron 41 데스크톱 앱 -- macOS 유니버설 DMG
  • 내장 터미널 (xterm.js + node-pty, 멀티 탭)
  • Diff 뷰어, 폴더 패널, 브라우저 패널 (보안 강화 웹뷰)
  • 오른쪽 사이드바 2분할 + 드래그 리사이저
  • 하단 패널: 터미널 / 브라우저 / 로그 / 활동 탭
  • 패널 상태 영속 저장
  • Claude fast mode 전달
  • claude-opus-4-8 모델 ID 사전 등록

v2.0.5 – v2.0.13 — 2026-05-10 ~ 26

기능

  • 인터뷰 모드: 구조화된 known/unknown 추적기, 라운드당 1-3개 질문
  • Goal 시스템: 길이 제한 없음, 자동 연속 실행, 타이머 누수 수정
  • 대시보드 git diff API + diff 패널 렌더링
  • Jawsidian 그래프 뷰 컨트롤
  • Web AI 관찰/자동화 프리미티브
  • steerPrompt가 Web/CLI에서 submitMessage를 실행

수정

  • AGY/Grok 재개 안정성 강화
  • 데스크톱 패널 Web/Electron 분리
  • CI 계약 복원

v2.0.1 – v2.0.4 — 2026-05-02 ~ 09

기능

  • 노트 이미지 붙여넣기 (원격 URL, 로컬 드래그, 클립보드)

  • Web AI 세션 관리 + 탭 풀 재사용
  • 노트 인라인 제목 레이아웃
  • 스킬 설치 시 모든 인스턴스로 전파

수정

  • Discord AllowedMentions 기본값
  • 업로드 콘텐츠 검증 강화
  • 인증 경로 및 프로세스 점검 강화
  • launchd status에서 실제 plist 포트 표시
  • npm 취약점 패치
